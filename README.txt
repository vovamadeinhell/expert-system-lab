# Лабораторная работа №1

Экспертная система с использованием прямой цепочки рассуждений.

## Запуск

Требуется Python 3.10 или новее.

```bash
python main.py
```

База правил находится в `rules.txt`. В базе содержится 16 правил, включая
демонстрационное правило с новым признаком `Экран_мерцает`.

## Возможности

- загрузка правил из отдельного текстового файла;
- правила вида `ЕСЛИ ... ТО ...`;
- логическая связка `И`;
- пустая рабочая база в начале консультации;
- прямой вывод с добавлением промежуточных фактов;
- автоматический выбор вопросов по активной базе правил;
- изменение вопросов после добавления правила с новыми условиями;
- отображение хода вывода;
- просмотр рабочей базы правил;
- добавление, изменение и удаление правил.

## Тестовый сценарий

Чтобы увидеть динамический вопрос из демонстрационного правила, запустите
консультацию. Система сначала запросит значение `Компьютер_включается`, а
после ответа `да` задаст новый вопрос `Экран_мерцает`. Если ввести `да`,
сработает правило:

`ЕСЛИ Компьютер_включается=да И Экран_мерцает=да ТО Диагноз=возможная_неисправность_монитора_или_кабеля`

Новые вопросы не перечислены в коде отдельно: система получает их из
условий правил в `rules.txt`. Добавьте правило через меню редактирования и
его новые условия появятся в консультации, если ведут к целевому диагнозу.
